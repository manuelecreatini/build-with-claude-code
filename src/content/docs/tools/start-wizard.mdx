Before Phase 0, it helps to know roughly what you are getting into. Answer three questions and the wizard puts together the playbook's heuristics for your kind of product. Every line links to the table it comes from.

The plan is a starting point, not a decision: in Phase 2 you confirm or change each choice, and record the changes in an ADR.
