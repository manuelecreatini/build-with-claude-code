The [master checklist](/reference/checklist/) and the Definition of Done of each phase, grouped by phase. A phase is finished when its Definition of Done is met: tick the items as you go and the tracker shows what is left.

**Copy as Markdown** gives you the same list with `[x]` marks, ready to paste into `docs/STATUS.md` so Claude can see it too.
