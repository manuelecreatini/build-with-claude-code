Phase 5 repeats the same [8-step loop](/phases/f5-build-loop/) for every build phase. Keep this page open in a tab next to your Claude Code session: it shows the current step and links to the page that explains it.

The two gates are where Claude stops and waits for you: **G5** before writing code (you approve the plan) and **G6** before closing the build phase (the Definition of Done is met and the pull request is merged). You cannot move past a gate until you tick it.
