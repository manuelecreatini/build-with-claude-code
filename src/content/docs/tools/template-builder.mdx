The [templates](/templates/t0/) use placeholders in angle brackets, like `<Product name>`. Pick a template, fill in the placeholders and copy the result, or download it as a file for your repository.

Placeholders you have not filled in yet stay highlighted in the result. Values carry over between templates, so you type the product name once.
