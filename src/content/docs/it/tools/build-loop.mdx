La Fase 5 ripete lo stesso [loop in 8 passi](/it/phases/f5-build-loop/) per ogni build phase. Tieni questa pagina aperta in una scheda accanto alla sessione di Claude Code: mostra il passo in corso e rimanda alla pagina che lo spiega.

I due gate sono i punti in cui Claude si ferma e aspetta te: **G5** prima di scrivere codice (approvi il piano) e **G6** prima di chiudere la build phase (la Definition of Done è rispettata e la pull request è in main). Non puoi superare un gate finché non lo spunti.
