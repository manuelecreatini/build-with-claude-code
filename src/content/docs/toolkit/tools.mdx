The right tool for each function, with its role in the playbook and costs verified in November 2026. The default choice is in bold.

| Function | Tools | Role in the playbook | Cost and limits |
|---|---|---|---|
| Dictation and capturing ideas | **Wispr Flow**; Windows dictation (`Win+H`); `/voice` in Claude Code; the Claude app's voice mode; meeting notes via a connector | Phase 1 brain dump; quick answers in the interviews; transcripts of user interviews. | Wispr Flow Basic free (2,000 words a week on desktop), Pro 15 USD a month (12 billed annually). |
| Discovery and specification | **`/wayfinder`**, `/grill-me`, `/grill-with-docs`, `/prototype`, `/research`, `/to-spec`; Claude Chat Projects and research; `/design` | Phases 1–3: decisions, research, prototypes, spec. | Included in the Claude subscription; the <Term id="skill">skills</Term> are open source (MIT). |
| Planning and <Term id="issue">issue</Term> tracking | **<Term id="git-github">GitHub</Term> Issues** (sub-issues, *blocked by*, labels, milestones), GitHub Projects, `gh`, `/to-tickets`, `/triage`; alternative: Linear | Decision map, <Term id="build-phase-bp">build phases</Term>, post-launch triage. | GitHub Free is enough. |
| AI development | **Claude Code** (<Term id="cli-terminal">CLI</Term>, VS Code, desktop app, web), Matt Pocock's skills, bundled skills, <Term id="subagent">subagents</Term>, <Term id="plan-mode">plan mode</Term> | The whole build loop. | Pro 20 USD a month (17 billed annually); Max from 100 USD a month. |
| Version control | **Git** + **GitHub**; GitHub Desktop as an optional graphical interface | Project history, one <Term id="branch">branch</Term> per phase, <Term id="pull-request-pr">pull requests</Term>. | Free. |
| Database | **Supabase** (Postgres, Auth, Storage, <Term id="rls">RLS</Term>), Supabase CLI for <Term id="migration">migrations</Term>, <Term id="mcp">MCP</Term> connector; alternative: Neon | Data, sign-in, files; versioned migrations. | Free: 2 active projects, paused after a week of inactivity. Pro from 25 USD a month with daily backups (7 days). |
| UI/UX and prototypes | **`/design`** (Claude Design), `/prototype`, shadcn/ui + Tailwind CSS; Figma optional | Mockups in Phase 3, interface variants, component system. | Included or open source. |
| Testing and debugging | **Vitest**, **Playwright**, Testing Library; Claude in Chrome; `/run`, `/verify`, `/debug`, `/diagnosing-bugs`; Lighthouse, axe DevTools | Test pyramid, assisted manual testing, bug diagnosis, accessibility. | Open source or included. |
| Deploy and hosting | **Vercel**, **GitHub Actions**, registrar (Cloudflare, Namecheap), Expo EAS for mobile | Previews per pull request, production, <Term id="cicd">CI/CD</Term>, domain. | Vercel Hobby free for non-commercial use only; Pro 20 USD per user a month. GitHub Actions: 2,000 minutes a month on private repositories (Free). |
| Monitoring and analytics | **Sentry**, **PostHog**, Vercel Analytics and Speed Insights, UptimeRobot or Better Stack | Errors, funnels, session recordings, <Term id="feature-flag">feature flags</Term>, performance, uptime. | Sentry Developer: 1 user, 5,000 errors a month. PostHog free every month: 1 million events, 5,000 recordings, 1 million flag requests, 100,000 exceptions. |
