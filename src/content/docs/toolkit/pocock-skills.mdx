**What they are.** The `mattpocock/skills` <Term id="repository">repository</Term> (MIT licence, about 307,000 stars on <Term id="git-github">GitHub</Term> in November 2026) collects the <Term id="skill">skills</Term> that Matt Pocock, author of Total <Term id="typescript">TypeScript</Term> and AI Hero, uses every day for "real engineering, not vibe coding". They are small, composable and adaptable, and they work with any model. They are not included in Claude Code: you have to install them (Phase 0, section 0.6).

**Who invokes them.** The README splits them into two groups. *User-invoked* skills start only when you type them (`/name`) and orchestrate a workflow; *model-invoked* skills can be invoked by you, but Claude also uses them on its own when the task calls for it: they hold the reusable discipline.

:::note[How names are written with the plugin]
With the <Term id="plugin">plugin</Term> every skill has the full name `/mattpocock-skills:<name>`; the short name `/<name>` works as long as no other command uses it. The only relevant collision: `code-review`, which in Claude Code is also a bundled skill. For Matt Pocock's version, type `/mattpocock-skills:code-review`.
:::

## The main flow, in one line

`/setup-matt-pocock-skills` → `/wayfinder` → `/to-spec` → `/to-tickets` → [`/implement` + `/tdd` + `code-review`] × N → `/triage`\
with `/handoff` between sessions, and `/diagnosing-bugs` and `/improve-codebase-architecture` when needed
