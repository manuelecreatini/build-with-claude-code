<WhyThisStep>Starting from an up-to-date `main` and a near-empty context means Claude works on the real state of the project, not on a memory of it.</WhyThisStep>

**PowerShell · session start**
```powershell
cd C:\dev\<project-name>
git switch main
git pull
claude
```
